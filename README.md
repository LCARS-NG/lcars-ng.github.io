# lcars-ng.github.io

Landing page of the Drupal theme LCARS-NG: <https://lcars-ng.github.io/>

One static page, served by GitHub Pages from the branch `master`, with no
build step, no script and nothing loaded from other sites. Colors, sizes and
the rules of the frame come from the theme (`css/lcars/tokens.css`,
`frame.css`, `navigation.css`, `components/panel/panel.css`).

- `index.html`, `css/style.css`: the page
- `images/screenshots/`: the screenshots of the theme README
- `images/logo.svg`, `favicon.ico`: the one-colored logo and the favicon of
  the theme
- `fonts/`: Antonio and Inter (the Latin part), taken from the theme, each
  under the SIL Open Font License 1.1 (`OFL.txt` next to it)
- `.nojekyll`: serve the files as they are

The theme itself: [drupal.org/project/lcars_ng](https://www.drupal.org/project/lcars_ng),
mirror on GitHub: [LCARS-NG/lcars_ng](https://github.com/LCARS-NG/lcars_ng).
